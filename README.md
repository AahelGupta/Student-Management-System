## 🎓 Overview

**Student Management System** is a modular Python backend application designed with **Object-Oriented Programming (OOP)** principles. It manages relational domains across **Students**, **Courses**, **Attendance**, and **Marks**, featuring automated reporting algorithms and performance insights.

---

## ✨ Key Features

- 🏗️ **Domain-Driven OOP Architecture**: Decoupled models for `Student`, `Course`, `Attendance`, and `Marks`.
- 📊 **Class Analytics Engine**: Automated processing of grade averages, attendance percentages, and Top 10 leaderboards.
- 🔄 **CRUD Operations**: Data mutation operations supporting record insertion, retrieval, modification, and deletion.
- 💾 **Data Persistence & Seeding**: Automated record initialization and flat data mapping workflows.
